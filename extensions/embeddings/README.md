# pystac-ext-embeddings

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Embeddings Extension](https://github.com/stac-extensions/embeddings).
This extension provides fields for describing geospatial embedding products, including the embedding type, dimensions, and other metadata.

## Supported versions

- [v1.0.0](https://stac-extensions.github.io/embeddings/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-embeddings** v1.0.0 corresponds to the [v1.0.0](https://github.com/stac-extensions/embeddings/releases/tag/v1.0.0) release of the **embeddings** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
